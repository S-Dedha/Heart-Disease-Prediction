# Heart-Disease-Prediction
This project focuses on predicting the presence of heard disease in patients using Logistic Regression, a supervised machine learning algorithm. The dataset used for analysis is sourced from kaggle which contains various medical attribute related to heart health.
The goal of this predictive analysis is to interpret the impact of different factors on heart health.

**Dataset Description**
Source: Kaggle (Heart Disease Dataset)
Type: Structured, tabular data
Feature: Age, sex, chestpain type,cholesterol level, maximum Heart Rate etc

**Tools And Technologies**
Python
Jupyter notebook
Numpy, pandas:Data manipulation
matplotlib, seaborn: Data visualization
Scikit- Learn= Model building and evaluation

**Methodology**
Data loading and manipulation
Data cleaning and preprocessing
Exploratory Data Analysis (EDA)

**Model training**
Using Logistic Regression

**Model Evaluation**
Confusion matrix, Accuracy score, Classification Report, ROC_AUC score

**Results**
Confusion matrix = [[24,6], [2,22]]
Accuracy Score = 0.85
ROC_AUC score =0.8986111111

**Conclusion**
The Logistic Regression model performs well with the accuracy of 85% and having a high ROC_AUC score of 0.89. It is especially effective in identyfing the patients with Heart Disease.
